# Consent Lottery v0.1.0

Research manuscript: **Private Participation in Agent Contract Selection: Exact Frontiers and Incompatible Optima**, Shivam Gupta.

This release contains the seven-page paper, source, proofs, four figures, two tables, literature audit, reproducible experiments and all saved distributions. The paper is a prospective AAMAS 2027 workshop manuscript; it has not been submitted or accepted.

Validation: 22 tests; 1,113 saved primary policies; 381 exact primal/dual certificates; 762 rationally verified small mechanisms; 675,840 exact event inequalities for 66 explicit cycle constructions. Claims concern the stated finite contract-selection model, not deployed LLM performance.

See README.md for reproduction, notes/PDF_QA.md for the delivered PDF hash, submission/SUPPLEMENT_METHODS.md for methodological information, and submission/STATUS.md for the outstanding venue dependencies.
